# Security Policy

## Supported versions

The latest release of the Community Edition is supported.

## Reporting a vulnerability

Do not open a public issue for security problems.

Email: ylh440104@gmail.com

Include steps to reproduce, the affected version (versionName from the APK), and the guest firmware involved if any. A proof of concept is welcome but not required.

Reports are answered within 14 days. Fixes ship through the normal release process: https://github.com/ylh440104/AEmulator-CE/releases

For anything that is not a vulnerability (crashes, firmware support, feature requests) use the issue tracker: https://github.com/ylh440104/AEmulator-CE/issues
